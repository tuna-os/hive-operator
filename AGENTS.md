# AGENTS.md — agent guide for tuna-os/hive-operator

**hive-operator** is a Kubernetes operator for the TunaOS Hive fleet. It manages rotation, healing, credential-sharing, and pacing through Kubernetes CRDs and controllers instead of shell CronJobs. Status: early (Shadow mode for reconciliation).

Human docs: [`README.md`](README.md) (overview, architecture, key concepts, metrics),
[`CONTRIBUTING.md`](CONTRIBUTING.md) (development setup and PR process).

## Build and Test

```bash
make generate manifests   # deepcopy, CRDs, RBAC (via go run)
make build                # compile the operator
make test                 # run tests
make run                  # run locally against kubecontext (dashboard :8082)
```

## Deployment

```bash
kubectl apply -f config/crd
kubectl apply -f config/rbac
kubectl apply -f config/manager
kubectl apply -f config/samples/fleet.yaml
```

## Key Facts

- **Language**: Go 1.22+
- **Pattern**: Kubernetes operators with CRDs and controllers
- **Reconciliation**: All controllers follow Observe → Shadow → Enforce progression
- **Metrics**: Prometheus metrics for alerting on fleet health
- **Controllers**: HiveSpoke, ModelLadder, SharedAuth (plus planned Watchdog, Nudge, Pace)

## Repository Structure

- **api/**: CRD type definitions (autogenerated deepcopy)
- **config/**: Kubernetes manifests (CRD, RBAC, manager, samples)
- **controllers/**: Reconciler logic
- **pkg/**: Shared utilities and metrics
- **docs/**: Additional documentation (e.g., rotation-promotion.md)
- **Makefile**: Build targets (generate, build, test, run)

## Important Implementation Details

Read the README section "Things that are true and not obvious" before modifying:
- **Auth**: Two credentials (internal reads vs. write sessions)
- **Session expiry**: Server is the authority
- **Status lag**: Use runtime files (hive.yaml.runtime, hive-state.json)
- **Backend/model switching**: Not transactional; verify after
- **Budget suppression**: Check `budget.BUDGET_EXHAUSTED` before concluding a stall
- **Bands**: Scale-specific; don't carry thresholds across benchmarks
- **Provider eligibility**: Unmeasured ≠ exhausted

## Controller Modes

Every controller reconciles through:
1. **Observe**: Read-only inspection
2. **Shadow**: Compute actions, record status/events/metrics without applying (`applied="false"`)
3. **Enforce**: Apply mutations (promote only after shadow matches incumbent)

Before promoting Shadow to Enforce, suspend the corresponding CronJob in the same change.

## Metrics and Alerting

Key metrics for alerts:
- `hive_agent_idle_seconds > 28800 and hive_budget_exhausted == 0`: Fleet stalled (not due to budget)
- `hive_shared_auth_consistent == 0`: Credential store out of sync (login won't propagate)

All metrics listed in README.
